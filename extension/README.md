# EmoJet — Browser extension

**Not built yet.** The plan is the same pipeline as the Android app (WhatsApp Web, Instagram, Gmail, any
site), running [Emojet v1](https://huggingface.co/subhadeep3902/emojet) locally through WebAssembly or a
small local server.

Interested in building it? The ranking algorithm is already written twice — in `Ranker.kt` here and in
`scripts/rank_sim.py` in the [model repo](https://github.com/subhadeeproy3902/emojet) — so the behaviour
to match is unambiguous. See [CONTRIBUTING.md](../CONTRIBUTING.md).
