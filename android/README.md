# EmoJet — Android

Not started yet — Phase 1 begins once JDK + adb are installed (see [`../docs/MANUAL-WORK.md`](../docs/MANUAL-WORK.md) §A).

Plan ([`../docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md)): Kotlin app; `llama-server` cross-compiled for arm64 and shipped in the APK's native-lib folder, started on localhost by an engine service; an `AccessibilityService` + overlay window for system-wide suggestions.
